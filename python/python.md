# Setting Up Python in VS Code

1. **Install Python:**
   - Download and install Python from [python.org](https://www.python.org/downloads/).
   - Add Python to your system PATH during installation.

2. **Install VS Code:**
   - Download and install Visual Studio Code from [code.visualstudio.com](https://code.visualstudio.com/).

3. **Install Python Extension for VS Code:**
   - Open VS Code.
   - Go to the Extensions view (`Ctrl+Shift+X`).
   - Search for "Python" and install the extension by Microsoft.

4. **Verify Python Installation:**
   - Open a terminal in VS Code (`View > Terminal` or `` Ctrl+` ``).
   - Type `python --version` or `python3 --version` to verify installation.

5. **Create a Python File:**
   - Open the Explorer view (`Ctrl+Shift+E`).
   - Create a new file with a `.py` extension, e.g., `hello.py`.

6. **Write Python Code:**
   - Open the Python file and write your code, e.g.:
     ```python
     print("Hello, World!")
     ```

7. **Run Python Code:**
   - Right-click inside the editor and select `Run Python File in Terminal` or use the Command Palette (`Ctrl+Shift+P`) and type `Run Python File in Terminal`.

8. **Configure Python Interpreter:**
   - Open the Command Palette (`Ctrl+Shift+P`), type `Python: Select Interpreter`, and choose the appropriate interpreter.
